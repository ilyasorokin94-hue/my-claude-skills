# Предложение по улучшению скилла (шаблон)

Одно предложение = один блок. Без «ок» руководителя блок лежит в
`uroki-vhodyashchie.md` клиники.

```
### П-ДДММ-N: короткое название
Что увидел: факт, дата, источник (страница справки, цифры журнала, снимок).
Что предлагаю: файл скилла и правка (новая строка D/S/R/M/Z/H, смена статуса,
шаг модуля, новая гипотеза).
Основание: сколько клиник или периодов, при той же ли рекламе.
Статус: доказано | наблюдение | гипотеза | миф | урок.
Риск: что будет, если правка неверна.
Решение руководителя: ок | нет | поправь (дата)
```

Пример:

```
### П-1911-1: не фильтровать роботов на счётчике карточки
Что увидел: 19.11.2026 неделя 09–15.11, нерекламные визиты Карт 96 без фильтра
и 59 с фильтром «не робот»; клики «Позвонить» 23 и 17. У визитов приложения Карт
признак робота пустой.
Что предлагаю: Z-02 в базу; card_weeks.py без фильтра, роботов отдельной колонкой.
Основание: одна клиника, 7 недель подряд одинаковая картина.
Статус: наблюдение.
Риск: если часть визитов приложения всё же роботы, заработанная часть завышена;
поэтому смотрим действия, а не только визиты.
Решение руководителя: вошло в 1.0.0 вместе со скиллом.
```
