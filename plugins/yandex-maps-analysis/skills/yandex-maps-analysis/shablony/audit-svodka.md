# Сводка аудита в рабочий чат (шаблон)

Сводка уходит после каждого запуска аудита, даже когда нового мало: по ней видно,
что обход отработал. Нет сводки к обычному времени — запуск не прошёл (ПК
выключен или спит, приложение закрыто), это повод проверить ПК.

**В сводке только счётчики и статусы.** Без текстов отзывов, без имён авторов и
пациентов, без телефонов, без цифр выручки. Подробности лежат в отчёте клиники и
в сессии аудита.

## Формат

Одна строка на клинику, в конце итог:

```
Аудит Карт, ДД.ММ, ЧЧ:ММ. Скилл X.Y.Z
[Клиника А]: заработанное сигнал вверх (+N%), звонки N принято / N пропущено,
  заявки с Карт N. Главная правка: темп отзывов. Нужен руководитель: 1
[Клиника Б]: заработанное шум, звонки N / N, заявки N. Главная правка: цена на 2 плитках
[Клиника В]: нужен вход
Итого: 3 клиники, аудитов 2, нужен вход 1, ждут руководителя 1. Минут: N
```

Что в строке клиники:

| Поле | Как писать |
|---|---|
| Заработанное | «сигнал вверх», «шум», «сигнал вниз» и процент. Внутри коридора только «шум» |
| Звонки | принято / пропущено за 2 недели |
| Заявки с Карт | число за 2 недели; нет выгрузки — «заявки: нет данных» |
| Главная правка | два-три слова, без подробностей |
| Статус | «нужен руководитель: N», «нужен вход», «блоков пропущено: N» |

## Отдельным сообщением сразу, не дожидаясь конца запуска

- до продления подписки 7 дней или меньше;
- карточка закрыта, ограничена или в спецрежиме;
- пропал подменный номер;
- чужой аккаунт в браузере, выход из аккаунта, капча;
- всё из раздела «Сразу звать руководителя» ([kompas/03-granicy.md](../kompas/03-granicy.md)):
  рейтинг упал на 0,1 и больше, два негативных отзыва за неделю, звонки упали
  больше чем на 30% при той же рекламе, похоже на атаку конкурента.

## Отправка

`python scripts/tg_report.py --file <файл сводки>` (или текст на стандартный
вход). Настройки скрипт берёт только из переменных окружения ПК; токен не вводим,
не читаем вслух и не пишем в файлы. Проверка без отправки:
`python scripts/tg_report.py --proverka`.

**Сводку всегда дублируй в сессии.** Если отправка в чат не прошла, так и напиши
первой строкой: «сводка в чат не ушла: причина».

Чат внутренний: клинике и пациентам через него ничего не пишем.
