# Список клиник обхода (шаблон)

Список для ежедневного обхода отзывов (модуль 02). Хранится на ПК агентства в
закрытой папке, **не в этом публичном репозитории**: в нём названия клиник и
пути к их закрытым папкам. Скопируй шаблон туда и заполни.

Обход идёт по строкам сверху вниз. Порядок выбирай так, чтобы клиники под
одним аккаунтом Яндекса шли подряд.

**У обхода аудита свой список** (модуль 08): там не порядок строк, а неделя А или
Б и день недели, потому что аудит идёт по одной клинике в день. Второй раз номера
организаций и счётчиков в него не переписываем: он ссылается на этот список.
Буквы клиник для обезличивания тоже общие на все скиллы агентства, своей таблицы
соответствия ни один список не заводит.

```
# Обход отзывов: список клиник
Обновлён: ДД.ММ.ГГГГ
Профиль Chrome для обхода: какой
Время обхода: ЧЧ:ММ, рабочие дни | каждый день

| № | Клиника | Закрытая папка с профилем | Аккаунт Яндекса | Статус |
|---|---|---|---|---|
| 1 | [Клиника А] | путь к папке | под каким аккаунтом открыт кабинет | работа |
| 2 | [Клиника Б] | путь к папке | … | только чтение |
| 3 | [Клиника В] | путь к папке | … | пауза |
```

- **Статус** повторяет статус из профиля клиники. «Пауза» = клинику
  пропускаем и пишем об этом в сводке.
- Ссылка на раздел отзывов, стиль ответов, телефон и почта для шаблонов
  живут в профиле клиники, а не здесь: список только говорит, куда идти.
- Автоответы включаются в профиле клиники (раздел «Ответы на отзывы»), а не
  здесь. Там же свой стиль ответов клиники: он главнее стартовых шаблонов
  модуля 02. Стиль, который выходит за общие границы по ответам, действует
  только при записи в «Решениях руководителя» профиля.
- Новую клинику в список добавляет руководитель или Claude по его «да».
