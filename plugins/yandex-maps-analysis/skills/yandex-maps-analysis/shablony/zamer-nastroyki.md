# Настройки замера позиций (шаблон)

Файл `zamer-nastroyki.md` лежит в закрытой папке клиники рядом с профилем,
**не в этом публичном репозитории**. Скопируй шаблон туда и заполни. Как
пользоваться: [moduli/07-zamer-poziciy.md](../moduli/07-zamer-poziciy.md).

```
# Замер позиций в Картах: настройки
Обновлён: ДД.ММ.ГГГГ
Карточка: название в выдаче, как её узнать (ID организации, адрес)
Двойник бренда: есть | нет (название и адрес, если есть)
Подписка: идёт | нет (номер кампании, с какого числа)

## Запросы
(10–15, словами пациентов; изменения только с записью в журнал)
1. стоматология
2. стоматология рядом
3. ...

## Точки
| Точка | Широта | Долгота | Зачем | С какого замера |
|---|---|---|---|---|
| У двери клиники | 00.000000 | 00.000000 | Ближний пациент | ДД.ММ.ГГГГ |
| Центр города спроса | ... | ... | Цель роста | ... |
| Ближнее кольцо, 2–5 км | ... | ... | Где карточка должна зарабатывать | ... |

## Услуги для «Как вас находят»
(4–6 направлений, по которым клиника хочет расти)
- ...

## Как мерим
Устройство и браузер: какой ПК, Chrome без входа в Яндекс
Масштаб: z=14 (или свой, но всегда один)
Время: примерно ЧЧ:ММ, будний день

## База и план
База: zamery/ДД.ММ.ГГГГ.csv (что было до правок)
Следующий замер: ДД.ММ.ГГГГ, после какой правки из журнала
```

Рядом с настройками папка `zamery/`: по одному CSV на замер (формат в модуле
07) и при желании `<дата>_kak-nahodyat.csv`.
