# Отчёт аудита раз в 2 недели (шаблон)

Отчёт руководителю агентства по одной клинике. Кладётся в
`otchety/audit_ГГГГ-ММ-ДД.md` рядом с профилем. Коротко, полными предложениями,
сначала главное. У каждой цифры источник. Отчёт клинике — отдельный файл, раз в
месяц, одна страница (раздел в конце).

Разделы ниже обязательные: пустой раздел не убираем, а пишем «нет данных,
причина». Так видно, чего аудит не проверил.

```
# Карты, [клиника]: аудит ДД.ММ (недели ДД.ММ–ДД.ММ)
Версия скилла X.Y.Z, этап: ведение. Длительность: N минут.

## 1. Итог в пяти строках
- Что изменилось:
- Сигнал или шум:
- Растёт ли заработанная часть:
- Главная правка на 2 недели:
- Что нужно от руководителя:

## 2. Цифры

| Показатель | 2 недели назад | Сейчас | Коридор | Вывод | Источник |
|---|---|---|---|---|---|
| Заработанные визиты (приложение + Навигатор без рекламы) | | | | | счётчик карточки |
| Купленные визиты (реклама Карт + Поиска) | | | | | счётчик карточки |
| Звонки принятые | | | | | кабинет, «Статистика» |
| Звонки пропущенные и доля | | | | | кабинет, «Статистика» |
| Маршруты | | | | | счётчик карточки |
| Заявки с Карт | | | | | CRM или Метрика сайта |
| Discovery, доля, место | | | | | кабинет, «Конкуренты» (какая неделя) |
| Отзывов за 30 дней, у нас и у выброса | | | | | публичные карточки |
| Мест в топ-3 из замера | | | | | замер позиций |

Внутри коридора пишем «не отличить от шума», а не «выросло».

## 3. Как представлена карточка и что изменилось
Тариф, название, рубрики, особенности, часы, телефоны, ссылки и метки, отметка
владельца, кнопки, врачи, обложка и первые фото. Дальше изменения за 2 недели,
разложенные по авторам: мы, Яндекс, пользователи, модерация, соседи.

## 4. Реклама
- Подписка: тип, даты, дни до продления, расход, переходы, действия, площадки, гео.
- Витрина или объявления:

| Плитка | Цена | Клики по `utm_term` | Заявки | Визиты | Вывод |
|---|---|---|---|---|---|

- Акция: есть, срок, видна ли в строке, совпадает ли с сайтом.
- Кнопка: куда ведёт, метка, заявок за 2 недели.

## 5. Каталог и фото
Списки с причиной у каждой строки: добавить · переименовать · дать фото ·
дать цену · убрать. Отдельно список кадров, которые стоит снять клинике.

## 6. Отзывы, конкуренты, запросы и позиции
Рейтинг, оценки, темп, доля ответов и медиана времени ответа, темы против
услуг. Местная норма и выброс, что у выброса поменялось. Спрос по 5 услугам,
места из замера: платные и бесплатные отдельно.

## 7. Путь до визита и утечки
Цепочка звонок → заявка → запись → визит, где рвётся, сколько теряется.
Самое слабое звено воронки: с него начинаются советы.

## 8. Свой взгляд
Проверка вне маршрута: что проверял, зачем, что получилось. Если ничего не
нашёл — что искал и почему.

## 9. Гипотезы и прогнозы
H-xx: данные за / против / молчат, предложение по статусу.
Созревшие прогнозы: сбылось / нет / не отличить от шума.
Сделано из прошлых советов: N из M, что именно и почему остальное нет.

## 10. Советы

### Сейчас
Одна главная правка и до 3 поддерживающих, которые бьют не в ту же цифру.
По каждому совету: что сделать · шаг воронки и цифра · ожидаемый эффект и срок ·
дата проверки · на чём держится (код знания со статусом и силой или «свой
вывод») · кто делает · цена · риск · готовая фраза «да, … по клинике <код>».

### В очередь
С причиной, почему не сейчас.

### Не делать
Коротко, чтобы никто не предложил это снова.

## 11. Что нужно
От руководителя: решения, фразы «да, …», входы.
От клиники: темп отзывов, фото, подтверждения, выгрузка заявок.

## 12. Как улучшить скилл
Предложения по шаблону predlozhenie.md или «Нового для скилла нет, потому что …».
Сюда же расхождения материалов агентства со скиллом, по одной строке.

## 13. Служебное
Версия скилла, длительность по блокам, какие блоки пропущены и почему,
в каком браузере работали, какую неделю показывал отчёт «Конкуренты».
```

Вместе с отчётом кладём: строку в `snimki.csv` ([snimok.md](snimok.md)), снимок
карточки в `snimki-kartochki/`, новую записку ([zapiska.md](zapiska.md)) и строку
в сводку ([audit-svodka.md](audit-svodka.md)).

## Отчёт клинике раз в месяц

Отдельный файл `otchety/klinike_ГГГГ-ММ.md`, одна страница, формат N-20
([normy-i-flagi.md](../baza-znaniy/normy-i-flagi.md)): что выросло и что упало
одной фразой; как было и как стало цифрами с источником; что сделали; что
дальше; что нужно от клиники. Не больше трёх решений для клиники.

Чего в нём нет: внутренних оценок конкурентов, цифр выручки, жаргона, данных
других клиник, обещания первого места. Отправляет руководитель, мы только
готовим.
