# Приёмы работы с инструментами

Не знания о Яндексе, а способы достать данные текущими инструментами: браузер
на ПК, расширение Chrome, кабинет, API. Они стареют быстрее, чем знания о
росте карточки, и сильной модели или новому инструменту могут быть не нужны.
Если у тебя есть путь лучше, иди им и предложи заменить приём в «Как улучшить
скилл». Номера прежние, чтобы ссылки из старых отчётов работали.

## Чтение Карт с ПК

- **Ограничения вывода.** Инструмент браузера фильтрует строки с «=», адреса с
  параметрами и длинные строки. Убирай URL, заменяй «=» на «: », отдавай
  результат короткими кусками. Сначала открой страницу, потом в отдельном шаге
  запускай скрипт.
- **Быстрый путь (Z-08).** Открой одну страницу Карт и в одном скрипте сделай
  `fetch('/maps/?ll=<lon>,<lat>&z=14&text=<запрос>', {credentials: 'omit'})` для
  всех запросов и `fetch('/maps/org/<id>/reviews/')` для соседей, `state-view`
  вырезай из HTML регуляркой. Так вся выдача и соседи читаются за 2 вызова.
- **Даты отзывов.** После клика «По новизне» бери `meta[itemprop=datePublished]`
  из DOM. `updatedTime` в `state-view` смешивает отзывы и ответы организации и
  идёт в сортировке «По умолчанию», для темпа отзывов он не годится.
- **Счётчик через API.** Текстовые фильтры по браузеру и ОС падают с ошибкой
  4009: клади их в измерения и фильтруй в коде. Длинные периоды режь по неделям.
