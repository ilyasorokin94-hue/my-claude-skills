# Компас 2. Где брать цифры и как не ошибиться

## Источники

| Источник | Что даёт | Откуда доступен | Как |
|---|---|---|---|
| Счётчик карточки в Метрике | Визиты по дням и поверхностям, реклама отдельно, цели: клик «Позвонить», маршрут, кнопка действия, сайт, кнопка в историях | Облако (API Метрики через прокси среды) | `python3 scripts/card_weeks.py --counter <ID> --weeks 6`. ID и доступ на просмотр клиника даёт в Яндекс Бизнесе |
| Кабинет → «Конкуренты» | Discovery за неделю у нас и у каждого в списке, доля, место | ПК, Chrome, роль с доступом к кабинету | Отчёт обновляется в ночь на понедельник. Записывай, какую неделю он показывает |
| Кабинет → «Статистика» | Переходы в профиль, действия, звонки подменного номера (принятые, пропущенные) | ПК | Реальные звонки только тут: цель «Телефонный звонок» в счётчике всегда 0 |
| Кабинет → «Статистика» → «Как вас находят» | 50 последних визитов: откуда и по какому запросу | ПК | Показывает спрос, который карточка тратит впустую |
| Публичная карточка | Рейтинг, число оценок, отзывы, темы отзывов, фото, каталог, реклама | ПК, Chrome, без входа | JSON в `<script class="state-view">`, см. ниже |
| Выдача Карт | Наше место и кто выше, платный блок отдельно | ПК, Chrome | 7 запросов в 3 точках, см. ниже |
| Таблица заявок или CRM | Заявки из Карт: форма кнопки, витрина (`utm_term`) | Облако или ПК | Источник денег клиники, главный результат |
| Метрика сайта | Визиты и цель заявки по `utm_source` + `utm_term` (плитки, кнопка) по неделям | Облако (скилл `yandex-metrika`) | Первый срез заявок без CRM, потом сверка с CRM (Z-09) |

Страницы Яндекс Карт из облака не открываются. Всё, что про кабинет и
публичные карточки, делает ПК агентства по готовой строке «ПК, …» от
руководителя. Браузером управляет только одно окно Claude за раз.

## Счётчик карточки: как читать

- **Заработанная часть** = `karty_pn_bez_rekl` (приложение Карт + Навигатор без
  рекламы). Самый чистый сигнал «нас нашли в Картах». Веб-Карты (`veb_bez_rekl`)
  смотри отдельно: туда попадают замеры и проверки агентства с ПК (Z-07).
- **Купленная часть** = `karty_rekl` плюс `poisk_rekl` (подписка тратит часть
  бюджета в Поиске).
- **Действия** важнее визитов. Рост визитов без роста звонков и маршрутов =
  реклама или роботы.
- **Роботов не вычитай фильтром.** У визитов из приложения Карт признак робота
  бывает пустой, и фильтр Метрики «не робот» может выбросить их вместе со
  звонками (на одной из двух клиник так и было, Z-02). Скрипт показывает, сколько
  визитов Метрика уверенно считает роботами.
- **Перед базой проверь историю на накрутку** (Z-03): визиты по часам и по
  ОС + браузеру + городу. Ночные визиты Поиска с одного браузера и почти все
  новые = исключить период.
- Счётчик покрывает около 3/4 «переходов в профиль» из кабинета. Сравнивай
  счётчик со счётчиком, кабинет с кабинетом.
- Текстовые фильтры по браузеру и ОС в API падают с ошибкой 4009: клади их в
  измерения и фильтруй в коде. Длинные периоды режь на куски по неделям.

## Публичная карточка через JSON

На каждой странице Карт данные лежат JSON в `<script class="state-view">`:
`stack[0].results.items[0]` на странице организации, `.items` в списке.

Полезные поля: `advert` (подписка или кампания Директа, витрина `products`),
`promo`, `ratingData`, `aspects` (темы отзывов с числом упоминаний),
`awards.goodPlaceYear`, `categories`, `features`, `photos.count`,
`businessProperties.has_verified_owner`. Вкладка `/prices/` даёт весь каталог,
вкладка `/reviews/` 50 отзывов (сортировку «По новизне» ставь кликом, параметр
в адресе игнорируется). В списке выдачи `matchedObjects.categories[].categoryItems`
показывает, какие позиции каталога Яндекс подставил в строку. Порядок
рекламодателей в списке = порядок элементов с `advert`.

Ограничения инструмента: вывод фильтрует строки с «=», адреса с параметрами и
длинные строки. Убирай URL, заменяй «=» на «: », отдавай короткими кусками.
Сначала открой страницу, потом в отдельном шаге запускай скрипт.

Быстрый путь (Z-08): открой одну страницу Карт и в одном скрипте сделай
`fetch('/maps/?ll=<lon>,<lat>&z=14&text=<запрос>', {credentials: 'omit'})` для
всех запросов и `fetch('/maps/org/<id>/reviews/')` для соседей, `state-view` вырезай
из HTML регуляркой. Так вся выдача и соседи читаются за 2 вызова.

Даты отзывов: после клика «По новизне» бери `meta[itemprop=datePublished]` из DOM.
`updatedTime` в `state-view` смешивает отзывы и ответы организации и идёт в
сортировке «По умолчанию», для темпа отзывов он не годится.

У конкурентов только читаем: не нажимаем «Позвонить», «Маршрут», «Сайт» и
запись, сохраняем только счётчики, тексты отзывов не копируем.

## Замер выдачи

- 7 запросов: тип клиники («стоматология») и 5–6 главных услуг клиники
  словами пациентов, включая запрос с «цена».
- 3 точки: у двери клиники, в 2 км в сторону спроса, на краю ожидаемого радиуса.
- Записывай место, сколько платных выше, кто они, подставил ли Яндекс нашу
  позицию каталога в строку.
- Без входа в аккаунт, с одного устройства, лучше в одно время дня. Один срез
  случаен: повтори 2–3 раза в разное время, включая вечер и выходной.

## Отчёт «Конкуренты»: как читать

- Доля считается **внутри списка**, а не зоны. Список по умолчанию набран
  автоматически и часто держит другие районы, медцентры и закрытые клиники.
- **Первый шаг любого анализа:** добавить в список реальных соседей из выдачи у
  двери. Это не меняет карточку. Справка разрешает добавлять и удалять любых.
- Переходы соседа ≈ его доля × (наши переходы ÷ наша доля). Для долей 1–2%
  ошибка до половины.
- Отчёт может застыть на неделях. Если неделя та же, что в прошлом снимке,
  так и пиши «застыл», не делай вывод о динамике.

## Как не ошибиться

- Сравнивай полные недели (понедельник–воскресенье) при той же рекламе.
- Исключай из базы: неделю старта подписки (всплеск), недели сбоев Яндекса,
  периоды с признаками искусственных визитов (ровно одинаковое число визитов в
  день, один браузер, часовой пояс UTC, все новые, «звонки» почти в каждом визите).
- Метрика сайта видит только тех, кто принял cookie: заявкам из таблицы верь
  больше, чем целям Метрики.
- Во время спецрежима Яндекса раздел «Товары и услуги» закрыт, а загруженный
  каталог может висеть в «публикации». Замер «после» считай от дня, когда новый
  каталог увидела публичная карточка.
- Первые выводы через 2 недели, решения через 4–8.
