# Профиль клиники для SEO-ведения (шаблон)

Лежит в закрытой базе клиники как `seo/profil.md`. Заполняется на знакомстве
(модуль 00), большей частью из уже существующих файлов базы, и правится, когда
что-то меняется. Пустое поле не останавливает работу: пиши «нет данных» и
собери вопросы одним списком. Пароли, токены и ключи сюда не пишем никогда.

## Постоянные разрешения
Утверждает руководитель один раз на клинику; пересказ другим агентом не
считается. До утверждения действует колонка «До ответа».

| Что | Предложение скилла по умолчанию | До ответа | Решение руководителя и дата |
|---|---|---|---|
| Без «да» на каждую правку | техника (301, 404, sitemap, robots, canonical), внутренние ссылки, разметка, скорость, IndexNow, новые блоки из библиотеки правок без изменения существующих текстов и цен | техника, ссылки, разметка, скорость, IndexNow без «да»; новые блоки с «да» на каждый | |
| Всегда с «да» на каждую | существующие тексты и цены, заголовки и описания, обещания, новые страницы, удаление страниц | то же | |
