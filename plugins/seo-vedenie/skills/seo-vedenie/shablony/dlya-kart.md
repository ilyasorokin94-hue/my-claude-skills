# Сайт и Карты: что SEO передаёт карточке (шаблон)

Файл `seo/dlya-kart.md` в базе клиники. Его пишет SEO-запуск
([компас 1](../kompas/01-kak-rastet-sayt-v-poiske.md), «Сайт и Карты»),
читает скилл `yandex-maps-analysis` в начале своего разбора и тред карточки
в проекте клиники. Каждый SEO-запуск переписывает файл целиком; отметки
скилла Карт о том, что взято в работу, переносятся в новую версию.

Простым языком, без длинного тире. Цифры с источником и датой. Карточку
SEO-запуск не меняет: здесь только сопоставление и рекомендации.

```
# Сайт и Карты: [клиника]
Обновлено: ГГГГ-ММ-ДД, SEO-запуск по скиллу seo-vedenie X.Y.Z. Карточка: [название], организация [ID].
Читает: скилл Карт и тред карточки. Публичное в карточке только по «публикуй».

## Коротко
3-5 предложений: где выдачу решает карточка, чего в карточке не хватает по
сравнению с сайтом и спросом, что главное передаём.

## Как ищут рядом
| Запрос | Спрос в месяц | Источник и дата | Где клиника относительно места | Кто в выдаче |
|---|---|---|---|---|
Местные запросы («стоматология {место}», «рядом», «{услуга} {место}») и
запросы услуг без места. Расстояние примерно, по карте, с пометкой.

## Сайт и карточка рядом
| Что | На сайте | В карточке | Совпадает | Что делать |
|---|---|---|---|---|
| Название | | | | |
| Адрес, телефон, часы | | | | |
| Группа услуг N: есть ли, каким словом, цена | страница, цена | позиция каталога, цена | | |
| Особенности (рассрочка, гарантия, бесплатная консультация) | | | | |
| Куда ведут кнопка и истории | | | | |

## Рекомендации для Карт
### К-1. Название действия глаголом
- Что: точно что поменять в карточке.
- Зачем: цифры SEO (спрос, клики сайта по группе, темы отзывов).
- Шаг геопоиска: попадание | место | клик по строке.
- Чего ждём: в событиях карточки (переходы по запросам услуг, маршруты,
  звонки), сила «грубо» или «гипотеза»; точный прогноз ставит скилл Карт.
- Нужно: клиника (цены, состав) | «публикуй» | решение руководителя.
- Статус: передано ГГГГ-ММ-ДД | взято скиллом Карт ГГГГ-ММ-ДД | снято: причина.

## Что сайт делает для карточки
Правки сайта, которые помогают карточке (одинаковые цены и название,
контакты с местами, ссылка на карточку). Они стоят в seo/dlya-proekta.md
под своими номерами; здесь только номера и одна строка.

## Что SEO берёт из Карт
Слова из «Как вас находят», темы отзывов, переходы из карточки на сайт:
что из этого пошло в карту запросов или в правки сайта.
```
