# Сводка для проекта клиники: все рекомендации по порядку (шаблон)

Один файл, с которого менеджер проекта и Claude в проекте начинают любой
вопрос про SEO: `seo/dlya-proekta.md` в базе клиники. Вся работа по
рекомендациям идёт в проекте клиники, поэтому файл обязан быть полным и
самодостаточным: по нему можно пройти сверху вниз и сделать каждую
рекомендацию, не открывая отчёт. Каждый разбор переписывает его целиком.

Пишется простым языком. Анализ и причины лежат в отчёте, здесь только то, что
нужно для работы. Длинное тире в файлах базы не ставим.

```
# SEO [клиника]: все рекомендации аудита по порядку
Обновлено: ГГГГ-ММ-ДД, разбор по скиллу seo-vedenie X.Y.Z. Следующий разбор: ГГГГ-ММ-ДД.
Это единственный файл, который нужен проекту по SEO. Свежая версия всегда в
репозитории базы клиники: перед работой возьми файл оттуда.

Как пользоваться: иди сверху вниз. Сделал: поставь [x] и дату, отправь базу в
репозиторий. Рекомендация не уходит из списка, пока не выполнена или не снята
с причиной.

## Коротко
4-6 предложений: как сайт находят в Яндексе и в Google, что главное сейчас и
в каком порядке действуем.

- Что: точно что сделать и где. Для правки сайта: ссылка на ТЗ

- Фраза: готовая строка, которой это запускается в проекте.
- Как проверить: что должно быть видно после.

## Как спросить в проекте
- «Что по SEO?» : прочитать этот файл из репозитория базы и пересказать.
- «Пройдёмся по рекомендациям SEO» : идти по списку сверху вниз, по каждой
  говорить статус и что нужно от руководителя.
- «Делаем рекомендацию N» : выполнить по её тексту и по правилам выкладки
  проекта, поставить [x] и дату, записать в seo/ot-proekta.md, отправить базу.
- «Я поменял на сайте …» : дописать строку в seo/ot-proekta.md.
- «Вопрос к SEO: …» : дописать в seo/ot-proekta.md.
```

Правила:

- **Все рекомендации, а не только срочные.** В список попадает всё, что нашёл
  аудит и разбор: действия в кабинетах, правки сайта, вопросы, работа с
  площадками, то, что отложено до замера. Находка без рекомендации остаётся
  в отчёте; рекомендация без строки в этом файле считается потерянной.
- **У каждой есть владелец, статус и срок.** «Когда-нибудь» не пишем: либо
  «сейчас», либо «после замера такого-то числа», либо в «чего не делать».
- **Номера сквозные и не меняются** от разбора к разбору: менеджер говорит
  «делаем рекомендацию 5», и это та же рекомендация, что была две недели
  назад. Выполненные переезжают вниз, в раздел «Сделано», с датой; номер за
  ними остаётся.
- **Порядок = порядок важности.** Сверху то, без чего остальное не имеет
  смысла.
- **Действия в кабинетах пишем готовой фразой** для компьютера с Chrome, с
  точным списком адресов и словами «больше в кабинете ничего не трогай».
- **Часть 2 честно объясняет, почему не сейчас.** Иначе её начнут делать
  раньше замера.
- Файл обновляется и тогда, когда новых рекомендаций нет: статусы, даты и
  «коротко» всё равно меняются.
