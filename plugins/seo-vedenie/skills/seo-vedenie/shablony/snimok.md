# Снимок цифр (шаблон)

Одна строка на каждый разбор в `seo/snimki.csv` базы клиники. Это наша
собственная история: кабинеты хранят данные ограниченно и иногда теряют или
догружают их задним числом. По снимкам считается обычный разброс и виден
квартал целиком.

Разделитель точка с запятой, даты ГГГГ-ММ-ДД, пустое значение = нет данных
(не ноль). Первая строка файла:

```
data;period_s;period_po;ya_nb_kliki;ya_nb_pokazy;ya_nb_poziciya;ya_brend_kliki;ya_v_poiske;ya_iks;g_nb_kliki;g_nb_pokazy;g_nb_poziciya;g_brend_kliki;g_v_indekse;sitemap_stranic;metrika_iz_poiska;zayavki_iz_poiska;otkrytyh_pravok;pometka
```

| Поле | Что это |
|---|---|
| `data` | дата разбора |
| `period_s`, `period_po` | границы 28 дней, за которые сняты цифры |
| `ya_nb_kliki`, `ya_nb_pokazy`, `ya_nb_poziciya` | Яндекс без бренда: клики, показы, средняя позиция |
| `ya_brend_kliki` | Яндекс, клики по запросам с названием клиники |
| `ya_v_poiske` | страниц в поиске Яндекса |
| `ya_iks` | ИКС |
| `g_nb_kliki`, `g_nb_pokazy`, `g_nb_poziciya`, `g_brend_kliki` | то же в Google |
| `g_v_indekse` | страниц в индексе Google из отправленных |
| `sitemap_stranic` | адресов в sitemap |
| `metrika_iz_poiska` | визиты из поисковых систем за период (Метрика) |
| `zayavki_iz_poiska` | заявки из поиска за период, по источнику из профиля |
| `otkrytyh_pravok` | правок без итога в журнале |
| `pometka` | чему в строке нельзя верить: «Вебмастер застыл с ДД.ММ», «простой сайта ДД.ММ», «смена домена», «плашка cookie с ДД.ММ» |

Правила:

- Период всегда 28 полных дней без последних 2–3. Если снято иначе, так и
  напиши в `pometka`.
- Строку с пометкой о сбое не используем для расчёта обычного разброса.
- Если кабинет догрузил данные задним числом, исправь старую строку и допиши
  в пометку «уточнено ГГГГ-ММ-ДД».
- Способ отделения бренда (регулярное выражение из профиля) один и тот же из
  разбора в разбор. Поменял выражение: пометка и пересчёт прошлых строк, если
  выгрузки сохранились.
