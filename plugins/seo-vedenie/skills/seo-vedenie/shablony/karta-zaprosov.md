# Карта запросов (шаблон для стоматологии)

Таблица «группа запросов → страница, которая должна по ней показываться».
Лежит в базе клиники как `seo/karta-zaprosov.md`. На знакомстве подставь адреса
страниц клиники, вычеркни услуги, которых нет, впиши спрос по региону клиники
и текущую позицию. Обновляется на пересмотре раз в квартал. Если у клиники уже
есть семантическое ядро, карта собирается из него.

Заготовка перенесена из инструкции агентства «SEO-мониторинг» v1.1. Для клиники
другого профиля группы свои, правила те же.

Правила:

- одна группа запросов = одна страница; если по запросу показывается другая
  страница сайта, это задача шагов Я10 и G6;
- коммерческие запросы («цена», «сделать», «{город}», «рядом», «клиника»)
  ведут на страницу услуги, а не на прайс и не на статью;
- информационные запросы («почему», «сколько», «что лучше») ведут на статью
  или на блок вопросов страницы услуги;
- брендовые запросы ведут на главную, запросы с фамилией врача на страницу
  врача;
- в крупном городе к каждой коммерческой группе добавляются варианты с
  районом и метро филиала;
- новая страница только при подтверждённом спросе в регионе клиники и если
  услуга есть в прайсе;
- группа карты = единица анализа: выводы, прогнозы и очередь правок строятся
  по группам, отдельно для Яндекса и Google
  ([компас 1](../kompas/01-kak-rastet-sayt-v-poiske.md));
- у главных групп три лидера выдачи и дата сравнения; группы, где выдачу
  решает карточка в Картах, помечены «карточка».

## Информационные темы

Сравнения («что лучше») часто уже разобраны на страницах услуг: тогда
отдельную статью не пишем, чтобы статья и услуга не спорили за один запрос.
Тему статьи выбираем так: спрос в регионе → что стоит в первой десятке →
нет ли раздела на странице услуги → страница услуги, на которую статья
ведёт → 3 кандидата с цифрами → выбирает руководитель.

| Тема | Спрос | Родительская услуга | Есть ли раздел на странице услуги | Статус |
|---|---|---|---|---|
