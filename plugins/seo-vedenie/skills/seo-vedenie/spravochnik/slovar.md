# Справочник. Словарь

Простыми словами, для отчётов руководителю и клинике. Перенесено из инструкции агентства «SEO-мониторинг» v1.1 (07.11.2026). Изменён только ритм: вместо «неделя, месяц, квартал» шаги идут каждый разбор (раз в 2 недели), через разбор и раз в квартал.

| Слово | Что значит |
| --- | --- |
| Профиль клиники | Файл `profil-kliniki.md` с данными одной клиники: город, регион, бренд, сайт, доступы без паролей, приоритеты. Инструкция берёт все {подстановки} из него |
| Регион Вордстата | Регион, по которому смотрят спрос: город клиники и, отдельно, область целиком. Записан в профиле |
| Показы | Сколько раз ссылка на сайт появилась в выдаче. Вебмастер считает только до 50-го места |
| Клики | Сколько раз по ссылке нажали |
| CTR | Доля кликов от показов в процентах: 100 показов и 4 клика = 4 % |
| Средняя позиция | Среднее место сайта в выдаче. 1–10 — первая страница, 11–20 — вторая |
| Брендовый запрос | Запрос с названием клиники («{бренд} {город}»). Небрендовый — без него («брекеты {город}»). Брендовые фразы отделяет регулярное выражение из профиля |
| Сниппет | Блок сайта в выдаче: заголовок (title), описание (description), адрес, иногда рейтинг и цены |
| Title и description | Заголовок и описание страницы в коде; из них поисковик чаще всего собирает сниппет |
| В поиске, индекс | Страница известна поисковику и может показываться по запросам |
| Переобход, запрос индексации | Просьба к роботу Яндекса или Google зайти на страницу ещё раз после правки |
| Sitemap | Файл sitemap.xml со списком страниц сайта и датами их изменения |
| robots.txt | Файл с правилами, какие разделы роботам не обходить |
| Canonical | Указание в коде, какая версия страницы главная, если есть копии |
| 301-редирект | Постоянная переадресация со старого адреса на новый; передаёт новому адресу накопленный вес |
| 404 | Ответ «страница не найдена» |
| Малоценная или маловостребованная | Статус Яндекса: страницу почти не ищут или она мало чем полезна, поэтому её не показывают |
| Дубль | Две страницы с одинаковым содержимым; в поиске остаётся одна |
| Страницы-двойники (doorway) | Почти одинаковые страницы под разные города или районы, где у клиники нет филиала. Google прямо относит их к спаму, Яндекс тоже понижает. Страница района допустима только с настоящим содержанием: как добраться, врачи, отзывы оттуда |
| Филиал | Отдельный адрес клиники. У каждого своя страница на сайте и своя карточка в Яндекс Бизнесе, 2ГИС и Google |
| ИКС | Индекс качества сайта Яндекса: градусник полезности и известности, а не рычаг для позиций |
| Спрос | Колонка Вебмастера и цифра Вордстата: сколько раз в месяц ищут фразу |
| Каннибализация | Две страницы сайта спорят за один запрос, и обе стоят ниже, чем могла бы одна |
| Карта запросов | Таблица «группа запросов → какая страница должна по ней показываться» |
| Хлебные крошки | Строка «Главная › Услуги › …» над заголовком страницы |
| Микроразметка | Подсказки поисковикам в коде страницы: клиника, врач, хлебные крошки, вопросы и ответы (стандарт Schema.org) |
| LCP, INP, CLS | Скорость по Google: как быстро виден главный блок (норма до 2,5 с), как быстро страница отвечает на нажатие (до 200 мс), насколько прыгает вёрстка (до 0,1) |
| E-E-A-T и YMYL | Опыт, экспертиза, авторитетность и надёжность автора и сайта. Для тем о здоровье и деньгах (YMYL) Google требует их строже всего |
| NAP | Название, адрес, телефон. Должны совпадать на сайте, в Яндекс Картах, 2ГИС, Google Картах и каталогах |
| Видимость в Алисе AI | Как часто Алиса AI в Поиске упоминает сайт в ответах по темам клиники |
| Стартовая проверка | Первая проверка новой клиники: заполняет профиль, карту запросов, точку отсчёта и список «Как поднять позиции» |
| D+14, D+28, D+56 | Замеры через 14, 28 и 56 дней от дня, когда робот увидел правку (не позже 14-го дня после выкладки). D+28 главный: после него страница открыта для новых правок |
| Как поднять позиции | Обязательный финальный раздел каждого запуска: полный список правок сайта по группам услуг, отдельно для Яндекса и Google, с прогнозом в кликах и очередью |
| Лидеры выдачи | Три сайта клиник из первой десятки по главному запросу группы в регионе клиники; с их страницами сравниваем свою |
| Пакет правок (ПК-N) | Правки одной выкладки по одной группе страниц; судятся вместе против контрольной группы |
| Контрольная группа | 3–5 страниц услуг, которые не трогаем до пересмотра: по ним видно, что сдвиг общий (спрос, сезон, поисковик), а не от правки |
| Коммерческие факторы | То, по чему Яндекс судит, похож ли сайт на настоящую клинику: цены, ширина услуг, рассрочка и оплата, гарантия, лицензия, контакты, запись |
| Внешний вес | Честные ссылки и упоминания клиники на других сайтах: справочники, медицинские площадки, профили врачей, местные СМИ |
| IndexNow | Протокол, которым сайт сам сообщает Яндексу об изменённых адресах сразу после выкладки; Google его не поддерживает |
| Прогноз в кликах | Спрос группы × разница долей кликов на целевой и текущей позиции: сколько кликов в месяц ждём от правки |
| Постоянное разрешение | Решение руководителя в профиле клиники: какие классы правок идут без «да» на каждую. Существующие тексты и цены не покрывает |
| Сезонность | Спрос, который каждый год падает и растёт в одни и те же месяцы (например, летом и в праздники) |
