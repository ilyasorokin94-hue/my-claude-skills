# Приёмы работы с инструментами

То, что стареет вместе с инструментами, а не с поисковиками: как снять цифру,
где кабинет подводит, что делать, когда не работает. Новые строки тем же
путём, что и знания ([rost-skilla.md](../rost-skilla.md)).

| № | Приём | Откуда | Проверено |
|---|---|---|---|
| T-01 | API переобхода Вебмастера может отвечать ошибкой 504 или пустым номером задачи. Тогда переобход вручную в кабинете: Индексирование → Переобход страниц | 3 клиники, с 07–14.11.2026 | 20.11.2026 |
| T-02 | Дневной лимит ручного переобхода виден в самом кабинете и меняется: в период сбоя было 10 адресов в день, вне его у одной клиники 60. Сначала страницы главной правки | 5 клиник | 20.11.2026 |
| T-03 | «Запросить индексирование» в Search Console есть только в интерфейсе, в API кнопки нет. Дневной лимит небольшой: у одной клиники около 8 адресов | 2 клиники | 17.11.2026 |
| T-04 | Вордстат в браузере отдаёт ноль по фразам с операторами (кавычки, восклицательный знак): такие фразы только через API из облачной среды | 1 клиника | 07.11.2026 |
| T-05 | Отчёт Вебмастера «Расширенная аналитика поисковых запросов по URL» готовится не сразу и хранится около 10 дней: заказать в начале разбора, забрать в конце | инструкция v1.1 | 24.10.2026 |
| T-06 | К расширению Chrome может быть подключено несколько браузеров, и сессии достаётся чужой. До первого шага посмотреть список браузеров и выбрать тот, что на этом компьютере. Номер в имени браузера ничего не значит | компьютер агентства | 22.11.2026 |
| T-07 | На Windows скрипты запускаются командой `python`, в облачной среде `python3`. Скрипты API-скиллов на bash идут через Git Bash | компьютер агентства | 22.11.2026 |
| T-08 | `sverka_stranic.py` читает страницу без выполнения скриптов. Если заголовок, описание или текст ставятся скриптом, сверка их не увидит: это и находка для аудита (часть роботов видит так же), и повод проверить страницу в браузере | сборка скилла | 22.11.2026 |
| T-09 | Сайт клиники может не открываться из облачной среды (нет в списке разрешённых доменов). Сверку страниц и обход делаем с компьютера агентства | 1 клиника | 11.11.2026 |
| T-10 | Просмотр выдачи в браузере без входа с регионом клиники в адресе запроса не проверен: Яндекс может ответить капчей. Тогда только Search API. Результат первого же применения записать сюда | сборка скилла | 22.11.2026 |
| T-11 | Сайт в Вебмастере подтверждается файлом в корне сайта, Search Console тоже. Эти файлы и ключ IndexNow при правках и выкладках не удалять: напоминать об этом в ТЗ, если правка трогает корень сайта | 2 клиники | 20.11.2026 |
| T-13 | Токены Вебмастера, Метрики и Search Console заданы в настройках облачной среды агентства и с компьютера агентства не видны. Цифры кабинетов снимает облачная сессия (модуль 05). Скиллы в среду ставятся из main репозитория: новая версия скилла доходит до облака только после слияния | базы клиник, компьютер агентства | 22.11.2026 |
| T-12 | В карточке Яндекс Бизнеса адрес сайта должен стоять без UTM-меток: оттуда Вебмастер берёт регион сайта | инструкция v1.1 | 24.10.2026 |
